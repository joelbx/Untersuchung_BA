Resolved the dark mode threshold issue. The public `colors.webpage.darkmode.threshold.foreground` option is an Int with default `256`. Existing `...threshold.text` settings map to it in saved YAML, `config.py`, and `:set` through the [configuration code](/app/qutebrowser/config/config.py). The [WebEngine mapping](/app/qutebrowser/browser/webengine/darkmode.py) uses `TextBrightnessThreshold` before QtWebEngine 6.4 and `ForegroundBrightnessThreshold` from 6.4 onward. The generated settings help and changelog are updated.
