Implemented default-on, opt-out telemetry in [telemetry.go](/app/telemetry/telemetry.go): it stores a stable anonymous UUID in `telemetry.json`, sends `flipt.ping` every four hours with the required version fields, and updates the timestamp only after a successful response. [Config](/app/config/config.go) supports both environment overrides; startup logs telemetry failures without stopping Flipt. The advanced example disables telemetry, and the release image uses a writable state directory.

Two native subagents handled the config and startup/info changes; I integrated and reviewed the patch. The full offline Go suite, the telemetry race test, and `git diff --check` pass. HTTP delivery was tested against a local server; the configured external collector endpoint was not contacted.
