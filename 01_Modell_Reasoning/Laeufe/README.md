# Endläufe: Modell / Reasoning

Die Unterordner sind nach Variante und Aufgabenblock geordnet. Innerhalb eines Aufgabenordners liegen die tatsächlich vorhandenen Originaldateien: result.json, offizielle Bewertung, Patch und Modellstufen. Ausschlüsse bleiben als Status sichtbar; ein fehlendes Originalergebnis wird nicht durch eine erfundene Datei ersetzt. Die vollständige Zuordnung steht in ../Endversuche.csv.
