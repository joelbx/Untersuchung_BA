Primary cause: lib/kube/proxy/forwarder.go newStreamer builds DataDir/log/upload/streaming/default and filesessions.NewStreamer requires that directory to exist (lib/events/filesessions/fileuploader.go CheckAndSetDefaults). lib/service/service.go initUploaderService creates this directory and starts the uploader, but lib/service/kubernetes.go initKubernetesService never calls it. A Kubernetes-only process therefore fails on interactive exec recording.

Cache key uses authContext.key; cache validation checks closed remote site only. CSR comes from Client.ProcessKubeCSR with no certificate lifetime check. exec, portForward and catchAll emit via req.Context or request.context; client cancellation can drop events. exec returns immediately on executor.Stream/sendStatus errors, bypassing final session or exec events.
