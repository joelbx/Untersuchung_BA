- src/components/views/elements/Pill.tsx is a default-exported class. load() combines URL parsing, entity lookup, async profile fetch, and state; render() combines type-specific text/avatar/class decisions, tooltip, and link behavior. A valid-looking message URL can throw because parsePermalink(url) may return null before parts.primaryEntityId is read. Explicit @room with no room can produce a classless pill because pillType is set even without room.

- src/utils/permalinks/Permalinks.ts exports getPrimaryPermalinkEntity and parsePermalink. The latter returns null for unsupported URLs. The existing code chooses parsePermalink for inMessage and getPrimaryPermalinkEntity otherwise; parsing should only determine identity, preserving the exact incoming href.
