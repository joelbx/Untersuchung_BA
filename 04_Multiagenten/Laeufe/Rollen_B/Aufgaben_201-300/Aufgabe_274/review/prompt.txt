ISSUE:
## Title
Support version-aware modes for
`qt.workarounds.disable_accelerated_2d_canvas`

## Description

`qt.workarounds.disable_accelerated_2d_canvas` is currently a Boolean setting,
so qutebrowser cannot express an automatic mode which depends on the QtWebEngine
Chromium version.

The setting must support three string values:

- `always`: always add `--disable-accelerated-2d-canvas`;
- `never`: never add the flag;
- `auto`: add the flag only on Qt 6 when the detected Chromium major version is
  available and lower than 111.

In `auto` mode the flag must be omitted on Qt 5, when the Chromium version is
unknown, and when the Chromium major version is 111 or newer. In particular, the
tested Qt 6.5 environment enables the flag, while the tested Qt 6.6 environment
does not.

The configuration schema must be migrated from a Boolean to a string enum so
that `always`, `auto`, and `never` are valid values. The default must be `auto`.


REQUIREMENTS:
- In `qutebrowser/config/configdata.yml`, change
  `qt.workarounds.disable_accelerated_2d_canvas` from `Bool` to a string setting
  whose valid values are `always`, `auto`, and `never`; set its default to `auto`.

- `_qtwebengine_args` must pass the active WebEngine version information, parsed
  CLI namespace, and special flags to `_qtwebengine_settings_args`.

- `_WEBENGINE_SETTINGS` must map:
  - `always` to `--disable-accelerated-2d-canvas`;
  - `never` to `None`;
  - `auto` to a callable resolver.

- The `auto` resolver must return `always` only when all of the following are
  true:
  - the runtime uses Qt 6;
  - `versions.chromium_major` is known/non-zero;
  - `versions.chromium_major < 111`.
  It must return `never` otherwise.

- `_qtwebengine_settings_args` must accept `versions`, `namespace`, and
  `special_flags`. If a setting resolves to a callable, call it with those values,
  use the returned enum key to obtain the final mapped argument, and yield the
  argument only when it is not `None`.

- Preserve the boundary behavior covered by the tests:
  - Qt 5.15.2, `auto` -> flag absent;
  - Qt 6.5.3, `auto` -> flag present;
  - Qt 6.6.0, `auto` -> flag absent;
  - `always` -> flag present on both tested Qt 6 versions;
  - `never` -> flag absent.


INTERFACES:
No new interfaces are introduced.

Independently review the already-applied patch. Run relevant existing tests.
