Primärer Einstieg: [run_context_main.py](run_context_main.py).

`Hilfsmodule/` enthält die von diesen Skripten verwendeten gemeinsamen Module. Namen anderer Architekturen darin sind Codeabhängigkeiten, keine zusätzlichen Experimente. Die Verzeichnisaufteilung ist eine Dokumentationsstruktur; für eine Ausführung müssten historische Pfade/Importpfade in einer separaten Arbeitskopie eingerichtet werden.
