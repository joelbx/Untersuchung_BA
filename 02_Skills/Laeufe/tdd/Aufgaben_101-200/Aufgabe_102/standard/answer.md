Added the Linux `locally_reachable_ips` fact with separate IPv4 and IPv6 lists. It collects local routes, normalizes addresses and prefixes, removes duplicates, and sorts the results. If a query is unavailable, it returns an empty list for that family with a warning. The change is in [linux.py](/app/lib/ansible/module_utils/facts/network/linux.py), with regression tests in [test_linux_locally_reachable.py](/app/test/units/module_utils/facts/network/test_linux_locally_reachable.py).
