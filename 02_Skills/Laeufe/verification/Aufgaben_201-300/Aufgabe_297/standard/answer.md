Implemented reverse proxy login in the checked-out repository. `ReverseProxyWhitelist` accepts comma-separated IPv4 and IPv6 CIDRs, individual addresses, and `@` for Unix sockets; an empty list disables the feature. Trusted requests use `ReverseProxyUserHeader` (default `Remote-User`) to find or create the user, update `LastLoginAt`, and return a session payload to the UI. Untrusted requests receive no `auth` payload. Nested log map values are redacted while their keys remain intact.
