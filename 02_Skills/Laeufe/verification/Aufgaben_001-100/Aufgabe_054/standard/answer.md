Added `GetInstance[T](constructor func() T) T` in [singleton.go](/app/utils/singleton/singleton.go). It caches by exact type, so `T` and `*T` have separate instances, and uses `sync.Once` to run each constructor once under concurrent calls.

Added tests in [singleton_test.go](/app/utils/singleton/singleton_test.go), including 20,000 concurrent calls. The race-enabled singleton tests, tests for packages using the existing helper, and `git diff --check` all passed.
